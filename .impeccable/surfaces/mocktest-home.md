# MockTest homepage surface brief

Mode: Persuade

## Direction contract

### THESIS
Show the real question experience so students understand what MockTest does, then make importing their own test the clearest next step.

### OWN-WORLD
Extend MockTest's existing paper-like surfaces, dark teal ink, restrained green actions, fine rules, rounded controls, and DM Sans typography. Keep the current workspace recognizable.

### STORY
Visitors see a genuine question from the bundled Database Midterm sample, learn that MockTest turns prepared JSON into timed practice and answer review, then import a test or open their existing test list.

### FIRST VIEWPORT
Put the existing MockTest wordmark and navigation at the top. Pair a direct headline and Import action with the real sample question. Label it as an example, show its four choices without revealing the answer, and include a brief note that review follows submission. Continue with the import → timed exam → review path and, when tests exist, show their real names and metadata from browser storage.

Selected concept: Question specimen, chosen by the user. Seed key: ae12f94b. Challenger lineage: Labanotation dance scores. Build path: code, preserving the established product visual system.
